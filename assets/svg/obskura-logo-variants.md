# Obskura logo sizes

All variants use the same curves, centered dots, and palette. Only the dark stroke weight changes. All SVGs have transparent backgrounds.

| Variant | Suggested rendered width | Stroke weight in 1000-unit viewBox |
| --- | --- | --- |
| `obskura-logo-micro.svg` | 16–31px | 44 |
| `obskura-logo-compact.svg` | 32–63px | 34 |
| `obskura-logo-standard.svg` | 64–159px | 23 |
| `obskura-logo-display.svg` | 160px+ | 14 |

The concept nav uses micro at 31px on desktop and 27px on mobile. `obskura-logo-code.svg` remains the original standard-weight version.
